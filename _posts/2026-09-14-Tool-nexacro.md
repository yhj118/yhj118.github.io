SI로 이직하고 첫 프로젝트 투입이 넥사크로를 활용한 개발이었다.
처음 들어보는 툴인데 접근할 땐 생각보다 크게 어렵진 않았다..
초보 개발자도 잘 다룰 수 있다. (근데 인터넷에선 구대기 툴로 통한다.)

넥사크로는 쉽게 말하면 버튼, 텍스트 입력창, 드랍박스, 그리드 등 컴포넌트 단위로 구성된 요소들을 마우스로 딸깍 그리는 거다.
그림판에서 네모난 도형을 그리고 싶으면 상단 메뉴바에서 네모 모양의 도형을 마우스로 딸깍 클릭하고 그리지 않는가?
똑같다고 보면 된다.

이런 컴포넌트들을 마우스로 딸깍 해서 UI로 그리고 각 컴포넌트마다 ID와 이벤트 부여해준다.
그리고 Dataset 컴포넌트를 추가해 실제로 서버와 통신할 데이터를 담는 그릇을 만든다.

이렇게 두 가지를 대상으로 스크립트 작성 공간에서 id와 이벤트 그리고 Dataset를 활용해 트랜잭션으로 서버와 통신을 주고받는다.
트랜잭션을 통해 사용자가 입력한 정보를 서버로 보내 DB에 저장한다거나 DB에서 조회한 정보를 그리드에 뿌린다거나.. 

뭐 이런 거고 이게 다다. 
UI 예쁘게 좀 꾸미고 싶으면 별도로 각 컴포넌트 속성에 class를 부여해서 꾸밀 수 있다.

투입 전에 미니 프로젝트(?)로 개간단하게 구현을 해봤다.
가장 중요한 구현 목적은, 해당 금융SI의 시스템 구조를 간략하게 파악하고 그 구조에 맞춰 넥사크로와 서버를 이용해 데이터 표현을 하는 것.

개발환경: win10
툴: nexacro17, eclipse
서버: Tomcat9
언어: java17, JS
대표 사용 인터페이스: nexacro x-api (nexacro와 서버 연동에 활용하는 api)
DBMS: oracle database
DB 언어: sql
DB 관리 툴: sqlDeveloper
